02Problem

Agents now read the outside world and act on it. Anything they read can give them orders.

REAL CASE · JUNE 2025 · CVSS 9.3

One email. Zero clicks. Data out.

EchoLeak (CVE-2025-32711): a single crafted email made Microsoft 365 Copilot leak internal data. It slipped past Microsoft's own prompt-injection classifier.

Why today's defences miss it

  • They read text, not what the model reads: white PDF text, hidden HTML, text inside images, base64, look-alike letters.
  • They stop at detection: when the filter misses, the agent still sends the email.
  • They leave no evidence: nobody can replay what the agent saw and why it acted.

Prompt injection is the top risk for LLM apps (OWASP 2025); agent goal hijack is #1 for agentic apps (OWASP 2026)

03Proposed solution

IntentSeal sits between the agent and everything it reads and does. Catch what can be caught, limit the damage, prove what happened.

01 · SEE

Sees what the model sees

11 input sources. Hidden PDF and Word text, hidden HTML, text in images (OCR), encodings decoded; pasted text split from the user's request.

02 · REMOVE

Removes only the attack

Offending spans are quarantined in place; the rest keeps working: of normal tasks still completed.

03 · GUARD

Checks every action

Allow-lists, fields pinned to the signed-in user, secret-leak scan, "did the user ask for this?", data-flow tracing, answer check.

04 · PROVE

Proves, triages, learns

Every decision logged with rule and attack type; replay, human approvals, an Investigator agent, a memory of confirmed attacks.

What is newTypical prompt filterIntentSeal

10Scalability, robustness & responsible AI

Built to run in production, and to fail safe when it is unsure.

Scale and operations

  • Fast path on CPU, p95 ms; AI judge only where needed, cached
  • Measured on one CPU process: 63 action checks/s, 20 message inspections/s (16 concurrent clients, 4 agents, 0 errors); scale out by adding containers with a shared PostgreSQL store
  • Multi-tenant: organisations, scoped keys, per-key rate limits, request size limits
  • 15+ model providers with key failover; local models for air-gapped sites
  • SIEM export (JSON Lines, CEF), metrics, health and readiness probes, graceful shutdown

Responsible AI

  • Rules decide, AI advises: a deterministic policy sits over every model output
  • Fail closed: content that needs the judge is held, never passed, if models are down
  • Human oversight: approvals, monitor mode, reviewer feedback, proposals a human applies
  • Privacy: redacted previews or hashes only; memory keeps fingerprints, not text
  • Transparency: every decision has a rule, reason, attack type and replay
  • Honest metrics: held-out benign set, third-party attack generators, published limits
