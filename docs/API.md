# API reference

Generated by `python scripts/export_openapi.py` from the gateway app (IntentSeal Gateway API 0.1.0). The full schema, with every request and response body, is [api/openapi.json](api/openapi.json); a running gateway serves it interactively at `http://localhost:8000/docs`.

**Authentication**: `Authorization: Bearer <key>`. Keys have a scope: *public* (read-only, the Console), *project* (an application: inspect, check, sessions, proxy) or *admin* (reviewers: approvals, policy, memory). Keys and organisations: [DEPLOY.md](DEPLOY.md). An application needs the *Engine* and *Sessions* calls; [INTEGRATION.md](INTEGRATION.md) shows them in context.

## Engine

| Method | Path | What it does |
|---|---|---|
| `POST` | `/v1/actions/check` | Check a tool call before it runs: tool, arguments, agent, session. Returns the decision, the arguments to run with (pinned fields rewritten), the contract ruling and a notice for the model. |
| `POST` | `/v1/actions/{event_id}/receipt` | Execution receipt: the application reports whether an allowed (or blocked) call actually ran. |
| `POST` | `/v1/inspect` | Inspect content before the model sees it: text or base64 file, source, agent, session. Returns the decision, cleaned content, findings and attack types. |
| `POST` | `/v1/outputs/check` | Check the model's answer before the user sees it: protected values redacted, or the answer withheld. |

## Sessions

| Method | Path | What it does |
|---|---|---|
| `POST` | `/v1/sessions` | Start a session with the user's task and trusted context; returns the session id and its intent contract. |
| `GET` | `/v1/sessions/{session_id}/contract` | D-064: every version of the session's intent contract (immutable, hash-chained), newest last. |
| `GET` | `/v1/sessions/{session_id}/events` | Every event of a session in order, with findings, decisions, actions, contract rulings and receipts (replay). |
| `GET` | `/v1/sessions/{session_id}/provenance` | D-065: attack-to-action chains (untrusted source -> content -> proposed call -> control -> outcome), built |

## Evidence

| Method | Path | What it does |
|---|---|---|
| `GET` | `/v1/costs` | Security spend across agents: decisions and judge tokens by tier. |
| `GET` | `/v1/costs/{agent}` | Security spend attributed to one agent: decisions and judge tokens/cost by tier (CORE-14). |
| `GET` | `/v1/decisions` | Decisions feed, filterable by decision, attack type, agent and time. |
| `GET` | `/v1/export/decisions` | Decisions as security events for a SIEM, oldest first: JSON Lines (ECS-style fields) or CEF lines. |
| `GET` | `/v1/scorecard/{agent}` | Latest evaluation reports and summary for an agent. |

## Review

| Method | Path | What it does |
|---|---|---|
| `GET` | `/v1/approvals` | Escalated actions waiting for (or resolved by) a reviewer. |
| `POST` | `/v1/approvals/{event_id}` | Approve or deny one escalated action. An approval lets the same call in the same session run once. |
| `POST` | `/v1/feedback` | Reviewer feedback: remember an event or content as a confirmed attack or a false alarm (attack memory). |
| `GET` | `/v1/investigations` | Recent Investigator reports. |
| `GET` | `/v1/memory` | Attack memory entries and counts (fingerprints only, never text). |
| `DELETE` | `/v1/memory/{memory_id}` | Forget one attack-memory entry. |
| `POST` | `/v1/sessions/{session_id}/investigate` | Run the Investigator on one session: it plans, uses read-only tools on the log, evidence, decoders, memory |
| `GET` | `/v1/sessions/{session_id}/investigations` | Investigator reports for a session. |
| `POST` | `/v1/suggestions/{suggestion_id}` | Apply or dismiss an Investigator proposal. Memory proposals are applied like reviewer feedback; policy |

## Policy

| Method | Path | What it does |
|---|---|---|
| `GET` | `/v1/policies/{agent}` | An agent's policy. |
| `PUT` | `/v1/policies/{agent}` | Replace an agent's policy. Validated against the policy schema, version bumped, written atomically. |

## Proxy

| Method | Path | What it does |
|---|---|---|
| `POST` | `/proxy/v1/chat/completions` | LLM proxy, OpenAI format, agent from the key or header. |
| `POST` | `/proxy/{agent_id}/anthropic/v1/messages` | Anthropic Messages API, protected: point the Anthropic SDK's base URL at /proxy/<agent>/anthropic. |
| `POST` | `/proxy/{agent_id}/gemini/v1beta/models/{model_action}` | LLM proxy, native Gemini format (generateContent, streamGenerateContent). |
| `POST` | `/proxy/{agent_id}/v1/chat/completions` | LLM proxy, OpenAI format: messages and tool results inspected, returned tool calls and answers checked, then forwarded to the agent's provider. |
| `GET` | `/proxy/{agent_id}/v1/models` | Model list for clients that discover models first (agent frameworks, chat UIs): the model the policy pins |

## Ops

| Method | Path | What it does |
|---|---|---|
| `GET` | `/healthz` | Liveness: the process is up (open, no key). |
| `GET` | `/readyz` | Readiness: database answers, policies load, Tier 1 classifier loaded. LLM providers are reported, not |
| `GET` | `/v1/metrics` | Decisions by type and rule, tier escalation rate, latency p50/p95 by tier, provider errors, memory. |
| `GET` | `/v1/whoami` | Which key is this? Lets the Console confirm a reviewer key is admin-scoped before showing reviewer actions. |

## Demo

| Method | Path | What it does |
|---|---|---|
| `POST` | `/demo/run` | Run a Playground scenario on the sandboxed reference agent, protection off or on. |
| `GET` | `/demo/scenarios` | Playground scenarios (generated attacks and benign cases). |

## Setup

| Method | Path | What it does |
|---|---|---|
| `GET` | `/v1/agents` | Registered agents and their modes. |
| `POST` | `/v1/agents` | Register an agent from a template (starts in monitor mode). |
| `GET` | `/v1/agents/{agent}/connect` | Copy-paste integration for this agent. Keys are placeholders: a project key comes from the gateway operator |
| `POST` | `/v1/agents/{agent}/self-test` | Self-test an agent's policy with structural probes. |
| `GET` | `/v1/providers` | Configured model providers and whether each has a key. |
| `GET` | `/v1/setup/templates` | Policy templates for registering an agent. |
