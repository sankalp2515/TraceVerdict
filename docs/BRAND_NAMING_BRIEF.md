# Naming brief (paste into naming tools)

## The product in one paragraph
A security gateway for AI agents. Companies now let AI agents read outside content (web pages, PDFs, emails,
tool results) and act on it (send email, query databases, call APIs). Hidden instructions inside that content
can hijack the agent. Our product sits around any agent: it inspects everything the agent reads, removes only
the malicious part, stops actions the user never asked for, and keeps a replayable record of every decision so a
security team can approve the agent with evidence. Promise: catch what can be caught, limit what a hijacked
agent can do, and prove what happened.

## Who buys and who uses
- Buyer / approver: security and risk leaders (CISO office, AppSec, AI governance) in enterprises and regulated
  industries (banking, insurance, healthcare, SaaS). India-first, global-ready.
- User: AI agent builders (developers, platform/ML leads) who need security sign-off without rebuilding.
- First audience: national hackathon judges and investors (ET AI Hackathon 2026, Accenture × Economic Times).

## What the name must signal (in priority order)
1. Trust and control at the boundary: a checkpoint, a gate, a guard that keeps the agent on its task.
2. Evidence and clarity: seeing what really happened (provenance, replay, proof), not fear.
3. Built for agents, not generic cybersecurity.
4. Calm, enterprise-grade confidence. Not hacker-edgy, not cute.

## Constraints
- 1–2 words, 4–10 letters preferred; easy to say for Indian and global English speakers; one obvious spelling.
- Works as: product name, GitHub repo, Python package (`pip install <name>`), domain (.ai / .dev / .io), and in
  a sentence ("protected by <Name>").
- Avoid: "AI"/"GPT"/"LLM" suffixes, "Shield"/"Guard"/"Sentinel"/"Armor" clichés unless genuinely distinctive,
  names of existing security products (e.g. Lakera, Prompt Security, Protect AI, HiddenLayer, Straiker, Lasso,
  Rebuff, Vigil, NeMo Guardrails, LlamaFirewall, Prisma AIRS), militaristic or fear-based imagery.
- Check before shortlisting: domain availability, GitHub/PyPI/npm name availability, trademark search (India
  IP India + USPTO/WIPO) in software/security classes (Nice class 9 and 42).

## Directions worth exploring (seeds, not finalists)
- Checkpoint / gatehouse / threshold metaphors (passage with inspection).
- Provenance / ledger / witness metaphors (proof of what happened).
- Navigation / keel / tether metaphors (keeping an agent on course).
- Coined words built from Sanskrit or Latin roots meaning gate, guard, witness or steadiness (check meaning in
  major languages for negative connotations).

## What we need back from the tool
10–15 candidates, each with: meaning/origin, one-line rationale against the four signals above, pronunciation,
likely domain/handle availability, and any obvious trademark conflict.

## After the name is chosen
Engineering finalises the brand with Kapferer's Brand Identity Prism (physique, personality, culture,
relationship, reflection, self-image), then the visual identity (logo direction, colour, type, voice) is applied
across the Console, README, deck and video via one config value plus the design tokens in DESIGN.md.
